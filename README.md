# ЛР-2. Индексирование данных и сравнение алгоритмов поиска

Над коллекцией людей строятся индексы по простым и составным атрибутам. Поиск по ключу и по диапазону выполняется двумя методами — бинарным поиском по отсортированной последовательности и АВЛ-деревом, — которые сравниваются между собой и с линейным перебором.

- [DESIGN.md](DESIGN.md) — ТЗ (дизайн).
- [PLAN.md](PLAN.md) — план по этапам и правила оформления кода.
- [bench/README.md](bench/README.md) — результаты замеров, графики и выводы.
- [docs/DEFENSE.md](docs/DEFENSE.md) — шпаргалка к защите.
- [docs/ЛР-2_теория.pdf](docs/ЛР-2_теория.pdf) — теория к защите в формате для телефона (исходник: docs/theory/THEORY.html; пересборка — печать в PDF через Chrome).
- [docs/memcheck](docs/memcheck) — проверка памяти: скрипт и логи санитайзеров и valgrind.

**Состояние:** 200 модульных тестов проходят в WSL (GCC 15), с ASan/UBSan, под valgrind и в MinGW (CLion); сборка без предупреждений с `-Wall -Wextra -pedantic`; утечек памяти нет.

## Структура

```
include/   шаблонные структуры данных и заголовки прикладной логики
src/       реализация прикладной логики и консольный интерфейс
tests/     модульные тесты (GoogleTest скачивается при первой конфигурации)
bench/     замеры времени, results/ — CSV, графики, выводы (bench/README.md)
docs/      материалы к защите
```

## Работа с программой

Главное меню программы `lab2`:

| Пункт | Что делает |
|---|---|
| 1. Данные | генерация людей (число, годы, seed, порядок), ручной ввод, загрузка и сохранение CSV, просмотр записей |
| 2. Индексы | построение индекса: атрибут или несколько атрибутов через пробел (составной ключ) и метод; список, содержимое, удаление |
| 3. Поиск | по ключу или диапазону через выбранный индекс; время поиска и автоматическая проверка линейным поиском |
| 4. Сравнить методы | все три метода на текущих данных по одному атрибуту: время построения и поиска |
| 5. Эксперимент | замеры на сгенерированных данных разных размеров и порядков, экспорт в CSV |

Пример первого запуска: «1 → 1» (сгенерировать, Enter на всех вопросах — 1000 человек), «2 → 1», ввести `2 7` (фамилия + год рождения) и метод `3` (АВЛ-дерево), затем «3 → 1 → 1» и ввести фамилию и год.

Формат CSV для загрузки: `id;last_name;first_name;middle_name;birth_year`, кодировка UTF-8.

## Сборка в CLion

1. **File → Open** → папка `Lab2`.
2. CLion подхватит `CMakePresets.json`. В **Settings → Build, Execution, Deployment → CMake** включите нужные пресеты:
   - `debug` — обычная отладка;
   - `release` — для замеров времени;
   - `asan` — проверка памяти санитайзерами, только с тулчейном **WSL** (MinGW санитайзеры не поддерживает).
3. Цели: `lab2` — программа, `lab2_tests` — тесты, `lab2_bench` — замеры.
4. Форматирование по правилам из PLAN.md: **Settings → Editor → Code Style → Enable ClangFormat**, затем Ctrl+Alt+L.

## Сборка из терминала (WSL)

```bash
cmake --preset debug && cmake --build --preset debug && ctest --preset debug
```

Проверка памяти (санитайзеры и valgrind, логи в `docs/memcheck`):

```bash
bash docs/memcheck/run_memcheck.sh
```

Замеры — см. [bench/README.md](bench/README.md).
